# Premium image direction

The homepage uses responsive WebP images with uncropped product silhouettes and less visual clutter. Catalog photos use the same studio setting and keep the full-size bottle about 1.6 times the mini's height. These are illustrative proportions, not verified physical dimensions of a manufactured product. The product label design is based on the repository's existing SUN&GLOW artwork.

- `hero`: a quiet riverside composition with room for HTML headings.
- `home`: the daily set on a sunlit table.
- `bag`: a palm-size mini in a running bag, without earbuds.
- `hand`: mist applied to an open palm.
- `story`: an adult runner with a small supporting mascot.
- `catalog-set`, `catalog-full`, `catalog-mini`: coordinated studio photography.

Hero and story: 2172×724 with 960×320 alternatives. All other images: 1200×800 with 600×400 alternatives. Mobile banner text sits above the image, so the photograph does not have to stretch behind it. The set catalog image has a small CSS crop of its surrounding empty space to align the bottle scale with the individual product images; bottle proportions are preserved.

Generated source PNGs remain in the task's image generation history. The site serves only these WebP derivatives. Titles, prices, form controls, and calls to action remain HTML. The purchase application and analytics behavior are unchanged by this visual refresh.
