# 이미지 품질 점검 및 로컬 개선

기존 PNG와 `brand-update/` 파일은 그대로 보존했습니다. 아래 검증 결과는 로컬 환경에서 확인한 내용입니다.

## 확인한 원인

- 기존 `hero.png`, `scenes.png`는 각각 1536×1024 PNG입니다. PNG의 손실 압축이 원인은 아닙니다. 이전 합성·확대 과정에서 이미 흐려진 디테일은 파일 크기나 선명도 필터로 복원되지 않습니다.
- `scenes.png`의 실제 칸 경계는 약 x=565/1037, y=345/672로, 동일 크기의 3×3 스프라이트가 아닙니다. CSS의 `300% 300%`와 등간격 위치가 실제 사진 경계와 맞지 않았습니다.
- 1440px 화면에서 세트 사진은 593×395, 사용법 사진은 579×386, 캐릭터 사진은 607×405로 표시됐습니다. 기존 러너 사진은 한 칸을 1180×787까지 늘린 뒤 높이 300px로 잘라 얼굴과 몸도 과도하게 잘렸습니다.
- 모바일에서는 정사각형 영역에도 배경 가로·세로를 각각 300%로 늘려 제품 비율이 왜곡됐습니다.
- 제목·설명·버튼은 이미 HTML 텍스트입니다. 이미지에 새 문구를 합성하지 않았습니다.

## 적용 내용

- 현재 제품 사진의 실제 경계에 맞춰 사진을 각각 추출했습니다. 제품 로고·모양·라벨을 다시 생성하거나 수정하지 않았습니다.
- 제품이 없는 캐릭터·러너 장면만 초기 커밋 `706da7a`의 더 선명한 원본을 사용했습니다. 해당 초기 제품 사진은 현재 라벨·로고와 다르므로 교체하지 않았습니다.
- 네이티브 크기 WebP는 무손실로 저장했습니다. 원본과 추출 좌표는 `manifest.json`에 있습니다. 제품 카드의 네이티브 출력은 원본 영역과 픽셀 차이 0을 확인했습니다. 배너는 아래 배경 보정을 추가 적용했습니다. 배너 768px 버전만 작은 화면을 위해 축소했습니다.
- `object-fit`으로 비율을 보존하고, 러너 사진은 기존 섹션 안에 최대 512px 너비로 전체 장면을 표시합니다. 이미지 크기를 명시하고 카드에는 지연 로딩, 배너에는 `srcset`과 우선 로딩을 적용했습니다.
- 제품·배너 사진의 화면 색감만 CSS `saturate(.90) contrast(.97)`로 약하게 낮췄습니다. 사진 원본 픽셀과 라벨 데이터는 유지됩니다. 브랜드 UI 색은 바꾸지 않았습니다.
- 최종 사진 자산은 약 3.85 MB에서 2.86 MB로 25.6% 감소했습니다. 768px 배너 대안·로고·백업·편집 소스는 비교에서 제외했습니다. 편집 소스와 백업은 페이지가 내려받지 않습니다. 실제 전송량은 화면·스크롤·캐시 상태에 따라 다릅니다.

## 추가 원본이 필요한 항목

| 용도 | 현재 소스 | PC 표시 폭 | 권장 2배 원본 |
|---|---:|---:|---:|
| 배너 | 1536×1024 (이전 확대 이력 있음) | 1440px; 큰 화면은 더 큼 | 최소 2880×1920, 가능하면 3840×2560 |
| 제품 세트 | 558×342 | 593px | 1200×800 이상 |
| 본품·미니·집·러닝백 카드 | 469~558px 폭 | 약 380px | 각 800×600 이상 |
| 사용법 손·팔 사진 | 469~558px 폭 | 579px | 각 1200×800 이상 |
| 브랜드 캐릭터 | 512×341 | 607px | 1220×820 이상 |
| 러너 사진 | 512×341 | 최대 512px로 제한 | 1024×682 이상; 전체 폭 사용 시 2400×1600 이상 |

큰 사진을 새로 확대하거나 제품 글자를 생성하지 않았습니다. 배너 주변 환경은 이미지 편집으로 자연광·잔잔한 수면·마른 석재 느낌으로 정리하고 큰 물보라·별빛 효과를 줄였습니다. 이후 기존 제품·캐릭터 영역을 마스크로 합성해 본품과 미니의 라벨을 보존했습니다. 큰 제품과 미니의 로고·문자 영역을 원본과 비교해 픽셀 차이 0을 확인했습니다. 제품 표면의 원래 작은 물방울은 유지했습니다.

- 배경 보정 소스: `source/background-retouch.png`
- 원본 전경 보존 마스크: `source/foreground-mask.svg`
- 직전 배너 백업: `previous/hero-1536.webp`, `previous/hero-768.webp`
- 최초 원본: 기존 `assets/hero.png`, `assets/scenes.png` 및 Git 이력에 보존

추가로 세트 사진 최대 558px, 캐릭터 최대 512px, 손·팔 사진은 각각 최대 558px·469px로 제한해 작은 소스의 불필요한 확대를 줄였습니다. 카드와 사용법 영역의 라벨은 기존 픽셀을 유지합니다. 높은 DPR에서 제품 글씨를 더 선명하게 보이게 하려면 위 표의 고해상도 제품 원본을 사용할 수 있으며, 현재 수정본은 이 파일 없이도 동작합니다.

## 검증

- 로컬 정적 서버에서 변경 전후를 같은 화면 크기·DPR 2로 촬영했습니다.
- 320·390·768·1440·1920px 화면에서 모든 새 이미지 로딩·비율·가로 넘침 및 신청 흐름을 확인했습니다.
- 제품 카드의 WebP 무손실 변환과 최종 배너의 제품 라벨 보존은 픽셀 비교로 검증했습니다. 부족한 해상도를 보충하는 업스케일·샤프닝은 하지 않았습니다.
- 공개 사이트는 이 환경의 네트워크 정책으로 접속할 수 없어 로컬 체크아웃에서 검증했습니다. GitHub 반영과 공개 사이트 배포 완료는 구분해서 확인해야 합니다.
