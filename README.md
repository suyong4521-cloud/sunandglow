# 내 랜딩페이지 관리 안내

성동 SESAC 6기 수업에서 만든 랜딩페이지입니다. 이 리포는 처음부터 여러분 계정 소유이고, 앞으로 여러분이 직접 고치고 키워 가면 됩니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 랜딩페이지 본문 |
| `result.html` | 신청 후 나오는 결과(전환 완료) 페이지 |
| `site.css` | 완료 페이지 디자인 |
| `privacy.js` | 신청 폼 처리 + 개인정보 안내 팝업 |
| `redesign.css` | 메인 페이지 디자인·모바일 레이아웃 |
| `base.css` | 공통 초기화·개인정보 안내창 |
| `assets/` 안 이미지 | 히어로·제품 이미지 |
| `robots.txt`, `sitemap.xml` | 검색엔진용 (Day 28~29) |

## 고치는 방법 (git 명령 필요 없음)

1. 리포 화면에서 고칠 파일(`index.html`)을 누르고 오른쪽 위 연필 아이콘을 누릅니다.
2. 글자를 고치고 **Commit changes**를 누릅니다.
3. 1~2분 뒤 `https://내아이디.github.io/`에 반영됩니다.

이미지는 리포 화면 **Add file → Upload files**로 `assets/` 폴더에 올리고, `index.html`에서 파일 이름을 바꿔 줍니다.

메인 페이지 브랜드 색은 `redesign.css` 맨 위 `:root`의 `--navy`, `--blue`, `--lime` 값으로 바꿀 수 있습니다. 문구와 버튼 링크는 `index.html`에서 수정합니다. 완료 페이지 디자인은 `site.css`와 `result.html`에서 관리합니다.

## 바꾸면 안 되는 것

- `id="cta-main"`, `id="lead-form"`, `id="cta-submit"`: GA4·픽셀 이벤트가 이 이름을 씁니다.
- `privacy.js`의 "입력값을 지우고 result.html로 이동" 부분.

## 분석 도구

GA4 측정 ID `G-YL5MC7J7NG`를 `analytics.js`에서 공통 사용합니다. 이벤트 명세·주요 이벤트 등록·향상된 측정 중복 방지·검증 방법은 [GA4 운영 설정](docs/ga4.md)을 참고하세요. 신청 체험 완료 이벤트는 `demo_lead_complete`이며 실제 판매나 리드 접수로 집계하지 않습니다.

`index.html`의 개인정보 안내에 행동 통계 측정을 안내합니다. 이름·연락처 입력값은 분석 도구에 전송하지 않습니다. Meta Pixel `1090501856926618`은 모든 HTML에 설치되어 있으며, GA4 이벤트 연동·전송 진단은 [Meta 픽셀 운영 설정](docs/meta.md)을 참고하세요. Microsoft Clarity·Schema JSON-LD 자리는 아직 주석으로 남아 있습니다.

## 개인정보 약속 (중요)

지금 이 페이지는 신청 폼에 입력한 값을 **어디에도 보내지 않고 바로 지웁니다.** 팝업에도 그렇게 적혀 있습니다.

나중에 폼을 Make, 구글 시트, 이메일 등에 연결해 실제로 정보를 받게 되면, 그 순간 팝업의 "절대 저장하지 않습니다" 문구는 거짓이 됩니다. 그때는 반드시 수집 항목, 목적, 보관 기간, 파기 방법을 적은 개인정보 처리방침으로 바꾸세요.


## 로컬 개발과 디자인 구성

별도 패키지 설치나 빌드는 필요하지 않습니다. 저장소 루트에서 다음 명령으로 정적 서버를 실행합니다.

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

메인 구성은 메인 배너 → 제품 세트 → 일상 활용 → 추천 상품 → 브랜드 스토리 → 사용법 → 필름 이미지 → 신청 안내 → 기존 신청 폼 순서입니다. 모바일에서는 카드와 입력 폼이 한 열로 배치됩니다.

- `assets/hero.png`: 메인·하단 배너용 생성 이미지입니다.
- `assets/scenes.png`: 승인된 시안에 맞춰 생성한 3×3 이미지 모음입니다. `redesign.css`의 `.photo`와 `.scene-*`가 각 칸을 표시합니다. 첫 줄은 세트·본품·미니, 둘째 줄은 집·러닝백·캐릭터, 셋째 줄은 손 분사·팔 분사·러너 이미지입니다.
- 필름 영역은 실제 영상이 없는 준비 중 상태입니다. 재생 기능이나 결제 기능은 추가하지 않았습니다.
- 기존 `cta-main`, `lead-form`, `cta-submit`, 개인정보 안내창 ID와 `privacy.js` 동작을 유지했습니다. 상품·장바구니 버튼은 신청 폼으로 연결됩니다.

확인할 항목: PC·모바일 가로 넘침, 이미지·CSS·JS 로딩, 메뉴 이동, 필수 입력 검사, 개인정보 안내 열기·닫기·동의, 신청 취소, 동의 후 입력값 삭제와 `result.html` 이동, 처음 화면 복귀. 입력 요소에 `name`을 추가하거나 외부 전송·저장 기능을 연결하지 마세요. 현재 개인정보 미수집 안내와 맞지 않게 됩니다.
